== Awesome F# https://awesome.re[image:https://awesome.re/badge.svg[Awesome]] 

F# is a programming language with focus on immutability, type inference,
first-class functions, powerful data types and pattern matching,
targeting .NET and other platforms.

This is a curated list of awesome F# frameworks, libraries, software and
resources.
